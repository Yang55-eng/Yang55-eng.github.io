免费分发一个技能：公众号、自建站与 GitHub Pages 怎么选

发布于 2026-09-24 杂记GitHub Pages

做完了技能，下一个问题是：怎么让同学装上？实测了三种免费渠道，结论是各管一段。

公众号：传播行，分发不行

个人订阅号未认证不能在正文插外部链接（唯一入口是文末「阅读原文」），也没有原生附件功能。发教程文章引流没问题，但安装命令没法在微信里执行。

托管平台：注意资源类型限制

WorkBuddy「发布为应用」托管静态站实测很快，但个别托管方会拦截 .zip/.cmd 等存档类资源（HTTP 403）。解法是把安装包 base64 内嵌进安装脚本，让脚本自包含，不依赖下载压缩包。

GitHub Pages：分发行，国内访问慢

免费、HTTPS、绑自定义域名也免费，不拦 zip。限制：站点 ≤1GB、月流量软上限 100GB、不支持后端。短板是服务器在国外，国内访问时快时慢——所以代码放 GitHub 仓库最合适（版本管理、Issue 收反馈），面向同学的分发页放在国内可直达的托管上。

最终组合（零成本）

  • 安装/分发：WorkBuddy 免费托管页（国内直达）
  • 代码与版本：GitHub 仓库 + 本站（Pages 托管项目页与教程）
  • 传播：公众号发教程文，文末「阅读原文」挂安装页链接
